# Recursos gráficos

Guardar únicamente fotografías, iconografía y otros medios con procedencia y autorización de uso documentadas.

- Fotografía real de las sedes: utilizar solo materiales con autorización.
- Material ilustrativo o generado: no atribuirlo a empleados, instalaciones, pacientes o trabajos reales.
- Optimizar WebP/AVIF, `srcset`, `sizes`, nombres descriptivos y `alt` contextual.
- No subir al repositorio público la copia original completa del sitio sin verificar derechos de redistribución.
